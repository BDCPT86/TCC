No binary assets required.
- Crowd, ball, players, stumps and all effects are drawn on the HTML5 canvas.
- Sound is synthesised at runtime with the Web Audio API.
- The club crest is an inline SVG (see LOH.crestSVG in js/ui.js). To use the
  official PNG instead, replace the crest markup with:
      <img src="path/to/tcc-logo.png" alt="Tygerberg Cricket Club">
